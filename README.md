# EBI Collectibles

Sealed Chinese Pokémon ecommerce site — TanStack Start (React, SSR), Postgres via
Drizzle ORM, Square for payments, deployed to Cloudflare Workers.

- Storefront: home, shop with filters/sort, cart, checkout, FAQ & shipping
- `/admin` — password-gated product and order management

See **[README-DEPLOY.md](./README-DEPLOY.md)** for local setup, database
migrations, Square configuration, and the Cloudflare deploy.
